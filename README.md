# Prueba Técnica - API REST USUARIOS

## Descripción 🧑‍💻
Este proyecto corresponde a la prueba técnica solicitada.
- El archivo `isebastian-1.0.0.jar` contiene la solución del sistema solicitado.
- El archivo `API-RES ISebastian.postman_collection` contiene una colección de Postman con ejemplos para consumir la API.
- La carpeta `isebastian` contiene el código fuente del programa para revisión

## Requisitos 🧑‍💻
- JDK 17 o 21 Instalado
  Comprobar instalación usando este comando en el CMD:
  java -version
- Postman para importar la colección (no obligatorio)
  1- Identificar el botón Import en la esquina superior izquierda de Postman
  2- Cuando se despliegue la ventana, arrastrar el archivo `API-RES ISebastian.postman_collection`

## Cómo ejecutar 🧑‍💻
- Ubicar el archivo `isebastian-1.0.0.jar`
- Abrir un CMD en la carpeta
  Click derecho -> Abrir en Terminal
- Ingresar el siguiente comando en el CMD:
  java -jar isebastian-1.0.0.jar
- NO CERRAR LA CONSOLA

## Cómo realizar pruebas 🧑‍💻
- Usando la colección de Postman o
- Swagger de la APP
  Acceder a la siguiente ruta en el navegador:
  http://localhost:8080/swagger-ui/index.html

## Verificar utilización de git 🧑‍💻
- Git instalado
  Comprobar instalación usando este comando en el CMD:
  git -v
- Acceder a la carpeta isebastian
- Abrir un CMD en la carpeta:
  Click derecho -> Abrir en terminal
- Ingresar el siguiente comando en el CMD:
  git log
- Se desplegarán todos los cambios hechos en las ramas main, develop, features y release.

## Detener el programa 🧑‍💻
- En la Terminal donde se esta ejecutando presionar la siguiente combinación:
  Ctrl + c
